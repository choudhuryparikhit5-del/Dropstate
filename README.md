# DropState — Shopify Store

A premium oversized streetwear brand with Shopify-optimized theme and full e-commerce functionality.

## Features
- Shopify Theme (Liquid templates)
- Product Management
- Collection Pages
- Shopping Cart & Checkout
- Size Guide
- Newsletter Integration
- Mobile-Responsive Design
- SEO Optimized

## Structure
```
├── theme/

│   └── config/
├── docs/

```
